## 📖 **导言**
许多研究都始于一个朴素的问题：  
“如果我们改变了 X，Y 会不会随之改变？”  

然而，现实数据往往无法直接回答。相关会冒充因果，隐藏变量悄然影响，反事实也永远无法被真正观察。  

因果推断正是为解决这些困难而建立的一整套方法。本书以直观示例介绍其核心工具——DAG、潜在结果框架、回归、倾向得分、工具变量与 RDD——展示如何在不完美的数据中尽量逼近真实的因果效应。
